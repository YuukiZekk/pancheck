名字里直接写了「特效字幕」的不用列。一行一个，照发布名里的写法： SGNB、Thor@HDSky、雅典娜。英文不分大小写，只认整段（SGNB 不会命中 LSGNBX）； 中文名出现在片名里不算（《逃往雅典娜》不会被认成雅典娜的盘）。改了要重新扫描。

执行（只搬不删）

开执行还差哪一步全是绿点才能执行；照 README「执行」一节逐项补。
界面只读锁定开了就在这台浏览器上隐藏批准与执行入口；它只能收紧，不能单独打开执行（服务端开关优先）。

查重区、待入库区要和片子在同一个网盘里（在「筛查范围」里设）。直连用 CD2 配置目录里的 API 令牌（列目录 / 建文件夹 / 移动），只在内存里用。
